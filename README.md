# CepteTurk

Приложение для изучения турецкого языка на русском: 5 курсов от алфавита до B2 (116 уроков), конспекты, 47 истории-диалога с озвучкой, карточки и упражнения.

- **Сайт:** https://asperasd.github.io/turkce/
- **Приложение:** https://asperasd.github.io/turkce/app/

## Бета-версия

- Аккаунтов и оплаты в бета-версии нет: все курсы открыты бесплатно.
- Прогресс хранится в браузере. Перенести его на другое устройство: Профиль → «Данные и резервная копия» → «Сохранить прогресс в файл», затем на новом устройстве — «Восстановить из файла».
- На телефоне сайт можно добавить на главный экран. Уже открытые уроки и их озвучка работают без интернета.
- В этом репозитории — только собранный сайт (результат сборки), а не исходный код.
