# Türkçe каждый день

Приложение для изучения турецкого языка на русском: курсы от алфавита до B2, конспекты, игры, истории с живой озвучкой, карточки и серия дней.

- **Сайт:** https://asperasd.github.io/turkce/
- **Приложение:** https://asperasd.github.io/turkce/app/

## Бета-версия

- Прогресс хранится в браузере. Перенести его на другое устройство можно в профиле: «Скачать копию», затем «Загрузить копию».
- Во время беты все уровни открыты бесплатно.
- Аккаунты, оплата, рейтинг и клуб появятся на основном сайте.
- На телефоне сайт можно добавить на главный экран, и он будет открываться как приложение. Озвучка уроков, которые вы уже открывали, работает и без интернета.
