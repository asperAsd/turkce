# Türkçe каждый день

Приложение для изучения турецкого языка для русскоязычных: курсы от алфавита до B2, игры, истории с живой озвучкой, карточки, словарь и серия дней.

**Открыть:** https://asperasd.github.io/turkce/

## Бета-версия

- Прогресс хранится в браузере на вашем устройстве. Чтобы перенести его, в профиле есть «Скачать копию» и «Загрузить копию».
- Рейтинг, клуб учеников и ИИ-репетитор появятся вместе с аккаунтами в полной версии.
- На телефоне сайт можно добавить на главный экран, и он будет открываться как приложение.
